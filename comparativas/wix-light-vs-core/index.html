Wix Light vs Core

Light sirve para una presencia online básica. Core es el salto importante si tu web tiene que cobrar, vender o funcionar como una herramienta de negocio.

VEREDICTO

Elegí Light para una web institucional, portfolio o sitio informativo. Elegí Core si necesitás aceptar pagos, ecommerce, reservas o más capacidad. No pagaría Core para una web que solamente muestra información.

Cuándo conviene Light

Wix describe Light como el plan para establecer una presencia online básica. Incluye dominio personalizado, elimina la marca de Wix y suma las funciones esenciales para publicar un sitio profesional. Para un profesional independiente, portfolio o negocio cuya web solo necesita explicar servicios y generar consultas, suele alcanzar.

Cuándo conviene Core

Core cambia el tipo de sitio que podés operar: Wix publica 50 GB de almacenamiento, herramientas para aceptar pagos, ecommerce básico, reservas y servicios, y hasta cinco colaboradores. Si la web tiene que producir transacciones directamente, Core tiene mucho más sentido.

¿Conviene empezar gratis?

Sí para probar el editor. Wix permite crear y publicar gratuitamente, pero necesitás un plan Premium para conectar un dominio propio y eliminar la marca de Wix. Además, cada plan Premium se aplica a un solo sitio.

¿Hay prueba gratuita?

Wix indica que no ofrece una prueba gratuita de los planes Premium. En cambio, ofrece una garantía de devolución de 14 días para el upgrade inicial.

Conclusión

Light vale si la web informa. Core vale si la web vende o cobra. Esa diferencia es más útil para decidir que comparar largas listas de funciones.
