COMPARATIVA · WIX

Wix Gratis vs Light: ¿cuándo conviene pagar?

El plan gratis sirve para probar Wix y publicar algo simple. Light empieza a tener sentido cuando tu web deja de ser un experimento y pasa a representar tu nombre, tu marca o tu negocio.

Veredicto rápido: quedate con Wix Gratis mientras estés probando. Pasá a Light cuando necesites dominio propio, quitar la marca Wix y presentar una web profesional.

La diferencia principal

FunciónWix GratisWix Light
Publicar una webSíSí
Dominio propioNoSí
Marca WixVisibleSe elimina
Atención 24/7Limitada según cuentaIncluida como plan Premium
Aspecto profesionalLimitadoMucho mejor
Pagos / ecommerceNoLight no es la opción principal para vender

Cuándo alcanza Wix Gratis

  • Estás aprendiendo a usar el editor.
  • Querés probar una idea antes de gastar.
  • La web todavía no se comparte con clientes.
  • No te importa usar una dirección de Wix ni mostrar su marca.

Para esa etapa, pagar antes de tiempo no aporta demasiado.

Cuándo Light empieza a tener sentido

Wix indica que para conectar un dominio personalizado necesitás un plan Premium. Light es el escalón pensado para una presencia online básica y profesional: portfolio simple, página institucional, CV, web personal o landing sin necesidades avanzadas de negocio.

¿Light sirve para vender?

Si tu objetivo principal es cobrar online, ecommerce o reservas, conviene mirar Core o un plan superior. Light está mejor orientado a presencia y contenido que a operaciones de negocio.

¿Hay prueba gratis de Light?

Wix no ofrece una prueba Premium separada, pero las primeras compras elegibles tienen una garantía de devolución de 14 días. Los precios varían según ubicación geográfica.

¿Se puede volver al plan gratis?

Sí. Si dejás vencer o cancelás el plan Premium, el contenido del sitio no se elimina. La web vuelve a una URL gratuita de Wix y reaparece la marca Wix.

Nuestro criterio

No pagues Light para “tener Wix Premium” si todavía no necesitás dominio propio. Pagalo cuando la imagen profesional tenga valor real para vos. Y si ya sabés que vas a vender o aceptar pagos, compará directamente con Core.
