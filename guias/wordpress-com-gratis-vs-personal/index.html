WordPress.com Gratis vs Personal: ¿cuándo vale la pena pagar?

El plan Gratis sirve para empezar sin riesgo. Personal tiene sentido cuando la web deja de ser una prueba y querés dominio propio, quitar anuncios y ampliar el sitio con plugins.

Veredicto rápido

Gratis para aprender, probar WordPress.com o lanzar algo muy básico. Personal para una web que quieras presentar como propia y hacer crecer sin saltar todavía a un plan más caro.

Cuándo elegir Gratis

Elegilo si todavía estás aprendiendo, querés probar el editor o no necesitás una presencia profesional. El hosting está incluido, podés publicar páginas y entradas sin límite y recibís 1 GB para archivos multimedia.

La contrapartida es importante: el sitio gratuito muestra anuncios de WordPress.com y no permite instalar plugins de terceros.

Cuándo pagar Personal

Personal es el primer salto que cambia de verdad el uso del sitio. Con facturación anual, WordPress.com publica un precio equivalente a US$4 por mes. Incluye 6 GB de almacenamiento, elimina los anuncios para visitantes y ofrece un dominio gratuito durante el primer año.

Además, WordPress.com permite instalar plugins en todos sus planes pagos. Eso abre acceso a decenas de miles de extensiones para formularios, SEO, membresías, tiendas y otras funciones.

¿Conviene saltar directamente a Premium?

No necesariamente. Premium cuesta más y añade ventajas como temas premium adicionales, Google Analytics, video y opciones de monetización con anuncios. Si solo querés una web profesional sencilla con dominio propio y plugins, Personal suele ser el punto de entrada más razonable.

El costo que no hay que olvidar

El dominio es gratuito únicamente durante el primer año cuando contratás un plan anual o multianual. Después se renueva aparte. Como referencia, WordPress.com publica actualmente US$13 al año para un dominio .com estándar, aunque el precio aplicable puede variar.

Vale o No

Vale pagar Personal cuando ya sabés que vas a mantener la web. Eliminar anuncios, usar un dominio propio y poder instalar plugins son mejoras suficientemente importantes como para justificar el salto desde Gratis.

No vale pagar todavía si estás explorando la plataforma o si la web es solo una prueba. En ese caso, empezá Gratis y subí de plan cuando realmente necesites esas funciones.
