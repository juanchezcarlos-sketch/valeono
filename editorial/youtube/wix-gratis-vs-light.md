## Guion
Wix gratis sirve para probar la plataforma, aprender el editor y montar algo básico. Pero si la web representa tu negocio, marca o portfolio profesional, el salto a un plan pago suele llegar rápido.

La diferencia no es solo estética. Con un plan pago podés conectar un dominio propio y eliminar varias limitaciones propias de una web gratuita. Eso cambia mucho la percepción de profesionalismo.

Entonces, ¿cuándo quedarte en Gratis? Si todavía estás experimentando, aprendiendo o validando una idea.

¿Y cuándo pasar a Light? Cuando la web ya tiene que representar tu marca de verdad, querés usar tu propio dominio y necesitás una presencia más profesional.

La recomendación de Vale o No es simple: no pagues Light solo para probar Wix. Pagalo cuando ya tengas una razón concreta para publicar una web profesional.
